# Limitations
- Announcement publication time is not necessarily the first executable trading time.
- A new trading pair does not necessarily represent a newly launched token.
- Initial source snapshots do not cover the entire intended research period.
- One market-day is insufficient for generalizable performance estimates.
- Candle data cannot always resolve intrabar event ordering or actual fills.
- Costs, liquidity, funding, survivorship bias and out-of-sample stability remain to be evaluated.
