# Data sources
Initial source snapshots were supplied on 25 November 2026:
- [Tokenearly listing timeline](https://tokenearly.com/en/listings): announcement discovery and monthly summaries.
- [CoinSight listing radar](https://getcoinsight.com/en/announcements): secondary announcement discovery and context.
- [Bybit announcement API](https://bybit-exchange.github.io/docs/v5/announcement): exchange announcement records.
- [Binance public market data](https://data.binance.vision/): historical futures candles.

Source categories are not equivalent to verified token launches. Historical coverage, identity, listing times, data quality and redistribution rights require separate checks. No third-party raw datasets are redistributed here.
